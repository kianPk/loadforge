# Security

## Reporting vulnerabilities

Email maintainers via GitHub security advisories on [kianPk/loadforge](https://github.com/kianPk/loadforge/security/advisories/new) with reproduction steps and impact.

## Authorized testing only

Loadforge is a **load generation** tool. Using it against third-party hosts without permission may violate law and acceptable use policies.

- Obtain explicit authorization before testing any non-local target
- Prefer staging environments and rate limits you control
- Do not use this project to disrupt production services

We do not condone denial-of-service or unauthorized penetration testing.
